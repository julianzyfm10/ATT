# Third-party task sources

- ToolSandbox scenarios: [Apple AIML Research ToolSandbox](https://github.com/apple-aiml-research/ToolSandbox). The source repository includes its own [license](https://github.com/apple-aiml-research/ToolSandbox/blob/main/LICENSE) and acknowledgements. This repository includes fixed task definitions derived from the scenarios. The original `Toolsandbox/` source folder is local only and is not included in Git.
- MCP-Bench task and server source: [Accenture MCP-Bench](https://github.com/Accenture/mcp-bench), revision `7a8eaeae83a842a2949080acc5473f65e1569daf`. The 30 fixed task definitions are derived from local MCP server tasks. The server implementations are retrieved separately by `scripts/setup_experiment4_mcp.ps1`.
